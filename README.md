# PHY Sports Page

Home-screen icons for the PHY Sports Page app.

- `icon/phy-icon-teams.png`: faded Eagles, Phillies and Sixers logos behind PHY, football field below (current)
- `icon/phy-icon-philly.png`: Philly skyline over the football field
- `icon/phy-icon-3sport.png`: three-sport icon (basketball, football, baseball)
- `icon/phy-icon.png`: original football icon
- `icon/icon.html`, `icon/icon2.html`, `icon/icon3.html`, `icon/icon4.html`: icon sources (logos in `icon/logos/`), rendered with `icon/shot.js` (Playwright)
